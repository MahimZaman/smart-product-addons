# Smart Product Addons

Configure WooCommerce product options with conditional fields and selection-based pricing.

## Installation and use

1. Place the `smart-product-addons` folder in `wp-content/plugins/`.
2. Activate Smart Product Addons in the WordPress Plugins screen.

Activate WooCommerce, create a product option group, and configure the fields, conditions, and prices for the relevant products.
